## SyntaxStudio 🎓
Every developer starts somewhere. This is where I started designing.

## Behind the Scenes
SyntaxStudio is a landing page for a full-stack development course, and I built every part of it myself using **HTML and CSS**. When I started, I had a blank file and a lot of questions. Today, I have a page I'm genuinely proud of.
There were moments I got stuck on the smallest things: spacing that felt off, an element that refused to align, colours that didn't quite work. Fixing them one by one taught me that good design is patience, and that's what made this project mean so much to me.

## Built With
- HTML5
- CSS3

## Note
This is the **design side** of the project. The buttons don't enroll anyone yet because I haven't built the backend and it's currently **optimized for desktop screens**, Mobile responsiveness is on my to-do list. I'd rather be upfront about where the project stands than pretend it's finished. This is step one of a bigger journey.
